# yt-cipher-via-vm
a rewritten http service of [kikkia/yt-cipher](https://github.com/kikkia/yt-cipher) that downloads the YouTube player script and uses [meriyah](https://github.com/meriyah/meriyah) AST parsing to locate the internal `URL` solver function (the one that calls `set("alr","yes")`), rewriting its assignment to expose it as `globalThis.__solve_url` then it runs the player inside a native nodejs vm with browser proxy mocking across a worker thread pool to decipher the `s` and `n` parameters in parallel.
